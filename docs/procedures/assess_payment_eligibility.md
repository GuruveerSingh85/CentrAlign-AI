# Procedure: assess payment eligibility

- **Document ID:** FIN-SOP-005
- **Version:** 1.0
- **Document type:** Procedure
- **Owner:** Finance Operations
- **Status:** Active (fictional)
- **Last updated:** 2026-10-01
- **Applies to:** Finance Operations Associate

Check the invoice, vendor, PO, receipt, duplicate state, approval history, payment status, and active run membership. All required approvals must be recorded, vendor must be Active and Verified, PO/receipt checks must pass, and no unresolved exception or prior/duplicate run membership can remain.

Return one of: ready to route for a required human approval, request information, hold, or escalate. Even a fully approved invoice is only a candidate for a separately authorized proposed run. The Associate cannot execute a batch or claim settlement.
