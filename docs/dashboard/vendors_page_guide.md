# Vendors page guide

- **Document ID:** FIN-DASH-003
- **Version:** 1.0
- **Document type:** Dashboard guide
- **Owner:** Finance Operations
- **Status:** Active (fictional)
- **Last updated:** 2026-10-01
- **Applies to:** Finance Operations Associate

The vendor list is `/vendors`; rows link to `/vendors/:vendorId`. The list includes category, verification status, payment terms, open invoice count, outstanding amount, and attention flag. The profile includes a fictional contact, status, last review date, currency, mock bank-details status, related invoices, related POs, internal note, and relevant policies.

Bank details are represented only by status and a masked synthetic placeholder. The portal contains no usable banking credentials and provides no edit or onboarding action. Pending Verification, On Hold, Inactive, or Change Under Review blocks payment-readiness recommendations until an authorized role resolves the status.
