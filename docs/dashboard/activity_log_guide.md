# Activity log guide

- **Document ID:** FIN-DASH-007
- **Version:** 1.0
- **Document type:** Dashboard guide
- **Owner:** Finance Operations
- **Status:** Active (fictional)
- **Last updated:** 2026-10-01
- **Applies to:** Finance Operations Associate

The Activity Log route is `/activity`. It displays 14 fixed, fictional events with timestamp, record ID, event text, and event type. Invoice, vendor, PO, and payment-run identifiers link to their detail pages.

The list is seeded historical data and does not include a real-time server audit stream. A payment-related activity item is not evidence of an actual transfer; the only settlement references are explicitly marked as historical mock evidence.
