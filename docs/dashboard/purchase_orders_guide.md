# Purchase orders page guide

- **Document ID:** FIN-DASH-004
- **Version:** 1.0
- **Document type:** Dashboard guide
- **Owner:** Finance Operations
- **Status:** Active (fictional)
- **Last updated:** 2026-10-01
- **Applies to:** Finance Operations Associate

The PO list is `/purchase-orders`; each `/purchase-orders/:poId` record displays vendor, department, requester, issue date, authorized amount, invoiced-to-date amount, remaining value, receipt status, and line-item scope. Detail pages link to vendor and associated invoices.

Compare invoice vendor, scope, total, and quantity with the PO. Receipt values include Not Received, Partially Received, Received, and Service Confirmation Pending. A partial receipt does not satisfy full receipt. Missing PO, vendor mismatch, amount overrun, or missing required receipt requires more evidence or escalation; do not edit the PO to make a match.
