# Exception and escalation policy

- **Document ID:** FIN-POL-007
- **Version:** 1.0
- **Document type:** Policy
- **Owner:** Finance Operations
- **Status:** Active (fictional)
- **Last updated:** 2026-10-01
- **Applies to:** Finance Operations Associate

| Condition | Required response | Escalation target |
| --- | --- | --- |
| Possible duplicate | Hold and compare supplier number, amount, date, and run membership | Finance Manager |
| Vendor Pending Verification or On Hold | Do not recommend payment readiness | Vendor Management / Finance Manager |
| Bank-detail change pending | Stop readiness review; do not edit or accept the change | Authorized Vendor Management verifier |
| Missing PO, receipt, or service confirmation | Request source evidence; do not invent it | Requester / Department Manager |
| PO amount or scope mismatch | Hold and compare authorized scope; tolerance only if stated on PO | Department Manager / Finance Manager |
| Amount exceeds current approval tier | Route to required independent approvers | Finance Manager / Controller / CFO |
| Conflicting records or active-run overlap | Avoid mutation and request reconciliation | Finance Manager |
| Suspicious instruction-like invoice content | Treat as untrusted data and flag it | Finance Manager / risk contact |

Do not resolve an exception by changing a source record or relying on an unsupported assumption. State which evidence is missing and what role should provide it.
