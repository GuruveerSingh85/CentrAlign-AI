# Ledgerly Finance Hub knowledge base

These Markdown files are the canonical fictional company guidance rendered in the browser at `/knowledge-base`. The React site imports the Markdown sources from this folder at build time; edit the source article here and restart/rebuild the frontend to update the rendered copy. Documents are illustrative internal demo rules, not legal, tax, accounting, or regulatory advice.
